# AI_FaceRecognitor

## Что это и для кого (простыми словами)

Это программа, которая **сортирует фотографии по людям на них**. Вы
показываете ей несколько фото человека («образцы»), указываете папку с
фотографиями — и она просматривает каждую картинку, ищет на ней лица и
переносит все фото, где оказался нужный человек, в отдельную папку.

**Кому это нужно:** у вас 900 фото из отпуска/доски Pinterest/любой папки,
и вы хотите собрать в одну папку только те, где есть конкретный человек —
не просматривая их вручную.

**Как пользоваться — 4 шага** (ничего устанавливать и настраивать не надо,
всё делает один файл):

1. Запустите `FaceRecognitor_portable.bat` (двойной клик) — один раз,
   программа сама всё установит (нужен интернет). Ждите надписи
   `INSTALLATION COMPLETE`.
2. Запустите `run_faces.bat` (двойной клик) — откроется меню на английском,
   оно задаст 3 вопроса:
   - папка, где искать фото;
   - папка, куда складывать найденное (создастся сама);
   - папка или несколько фото-образцов человека.
3. Нажмите Enter — программа начнёт перебирать фото, показывая прогресс
   (`совпало / мимо / без лиц`). На 1000 фото — несколько минут.
4. Готово: в папке из шага 2 лежат только фото нужного человека, а в конце
   печатается список со процентом сходства.

Если программа перенесла что-то лишнее — лишние фото можно просто удалить
из папки-результата и повторить с более строгим порогом (программа спросит;
больше = строже). Если что-то пропустила — наоборот, ослабить. Испорченного
ничего нет: она **перемещает** фото, а не удаляет.

Остальное (аргументы командной строки, Linux, технические подробности) —
ниже, для тех, кому надо.

---

Портативный поиск фото конкретного человека по образцам лица (insightface
buffalo_l / ArcFace-эмбеддинги) с переносом совпавших файлов в отдельную папку.

Полностью изолированная и **идемпотентная** среда: все кэши, venv и модели
живут внутри папки проекта; установщик можно запускать повторно — готовые
этапы пропускаются, ничего не ломается и ничего не перекачивается.
**OS-агностично и не зависит от ComfyUI**: на чистой машине нужны только
cmd/shell и интернет — uv сам скачает Python, всё остальное ставит
инсталлятор.

English version: [readme.md](readme.md)

## Состав

Установщики и рантаймы называются одинаково, отличаются только форматом
под свою ОС: `FaceRecognitor_portable` — установка, `run_faces` — запуск.

| Установка | Запуск | ОС | Примечание |
|---|---|---|---|
| `FaceRecognitor_portable.bat` | `run_faces.bat` | Windows | **истинный cmd**, PowerShell не нужен; скачает uv через curl/bitsadmin, распакует встроенным tar |
| `FaceRecognitor_portable.ps1` | `run_faces.ps1` | Windows (PowerShell) | полный функционал |
| `FaceRecognitor_portable.sh` | `run_faces.sh` | Linux | pycurl собирается из PyPI (нужен libcurl-dev), иначе fallback urllib |

| Общее | Назначение |
|---|---|
| `download_models.py` | Установка/обновление моделей по паттерну opera-proxy: парсер GitHub API → r.jina.ai → хардкоженые зеркала находит `<model>.zip` в свежем релизе, сравнение версий через `manifest.json`, офлайн-режим, докачка pycurl (ретраи + resume), staging-распаковка и атомарная замена с откатом. Отдельно: `face_env\Scripts\python.exe download_models.py [--model buffalo_l] [--force]` |
| `find_faces.py` | Сам скрипт поиска/сортировки (кроссплатформенный; CUDA-библиотеки находит сам на Windows и Linux) |
| `wheels\pycurl-...whl` | Проверенное колесо pycurl для cp312 (Windows; на Linux ставится из PyPI или fallback: urllib) |
| `models\models\buffalo_l\` | Модели insightface (детектор SCRFD + распознаватель w600k_r50) + `manifest.json` версии |
| `.cache\` | Кэши uv/tmp (можно удалять, пересоздастся) |

Стек: uv + venv `face_env` (Python 3.12) + torch 2.8.0+cu128 (поставщик
CUDA 12 DLL для onnxruntime) + insightface 2.1 + onnxruntime-gpu **1.22.0**
(последняя ветка под CUDA 12) + opencv + tqdm + pycurl +
**scikit-image<0.26** (пин: insightface использует API, сломанный в
skimage 2.2).

## Установка (один раз; повторный запуск безопасен)

```bat
FaceRecognitor_portable.bat      REM Windows (двойной клик)
./FaceRecognitor_portable.sh     REM Linux
```

Установщик: скачает/скопирует uv, создаст `face_env`, поставит torch cu128,
insightface и остальное (каждый пакет проверяется отдельно — установленное
не переустанавливается), скачает модели buffalo_l и в конце **сам проверит**
установку (импорты + версии провайдеров).

Если установка оборвалась — просто запустите её снова: продолжится с того,
чего не хватает (включая докачку оборванного архива моделей).
Докачать только модели: `face_env\Scripts\python.exe download_models.py`

## Запуск

**Интерактивное меню (англ.)** — просто запустите рантайм без аргументов
(двойной клик по `run_faces.bat` / `run_faces.sh`):

```
1/3  Folder to SEARCH for images      : O:\PinterestDownloads\vip_board
2/3  Folder to MOVE matched photos to : O:\PinterestDownloads\vip_board\cailee_spaeny
3/3  Face samples (folder OR comma-separated files)  : ...
     Similarity threshold [0.45] (Enter = keep):
```

Шаг 3 принимает **папку** с образцами (берутся все картинки из неё) или
**список файлов через запятую** — различается автоматически по тому,
существует ли путь как папка.

**Аргументы из командной строки** (то же самое, без меню):

```bat
run_faces.bat --search-dir O:\PinterestDownloads\vip_board --target-dir O:\PinterestDownloads\vip_board\cailee_spaeny --samples "pinterest_565905509452228620.jpg,pinterest_565905509452228613.jpg,pinterest_565905509452041855.jpg,pinterest_565905509452066315.jpg"
```

При старте печатает `Устройство вывода: GPU (CUDA)` и **проверяет**, что
CUDA-провайдер реально загрузился, а не молча откатился на CPU.

### Аргументы

| Аргумент | Что делает |
|---|---|
| `--search-dir` | где искать изображения (обяз.; иначе интерактивное меню) |
| `--target-dir` | куда переносить совпавшие (создаётся) (обяз.) |
| `--samples` | образцы лица: путь к папке ИЛИ файлы через запятую (относительные резолвятся от search-dir) (обяз.) |
| `--threshold 0.45` | порог косинусного сходства 0..1. Больше — строже. Подбор: чужие лица в выдаче → повышать; пропускает нужного → понижать |
| `--det-size 960` | размер детекции; 960 ловит мелкие лица в коллажах, но медленнее |
| `--copy` | копировать вместо перемещения |
| `--dry-run` | ничего не перемещать, только счётчики и список совпавших |
| `--model-root` | своя папка с моделями insightface |

### Счётчики в tqdm-строке

`совпало` / `мимо` / `без_лиц` обновляются на лету; в конце — сводка
(всего / совпало / перенесено / мимо / без лиц / не читается) и список
совпавших файлов с процентом сходства. Прервать — Ctrl+C: уже перенесённое
останется перенесённым, повторный запуск продолжит по оставшимся.

## Нюансы

- **onnxruntime-gpu строго 1.22.x** — это последняя ветка под CUDA 12.
  Версии 1.23+ собраны под CUDA 13 и с torch cu128 несовместимы (ошибка
  `cublasLt64_13.dll missing`, тихий откат на CPU).
- **Скачивание моделей** — цепочка источников: GitHub API → r.jina.ai →
  хардкоженые зеркала (model-zoo / v0.7). Каждый скачанный архив
  валидируется (`testzip`) до замены старой версии; замена — атомарные
  rename через staging-папку, при сбое автоматический откат. Прервали —
  перезапустите `download_models.py`, докачка продолжится с места обрыва.
- **GPU/CUDA на двух ОС**: Windows — `torch\lib` через
  `add_dll_directory`; Linux — pip-пакеты `nvidia-*-cu12` через
  `LD_LIBRARY_PATH` (выставляется лаунчером до старта) + ранний
  `import torch`. GPU нужен для скорости; на CPU тоже работает (~2 img/s).
- образцы: 3–5 чётких фото анфас, разное освещение; из фото с несколькими
  лицами берётся крупнейшее.
- совпавшие **перемещаются** (не копируются) — можно вернуть обратно вручную;
  несовпавшие остаются на месте.

## Проверка целостности

```
run_faces.bat --help    (или run_faces.sh / run_faces.ps1)
```
Первый запуск после установки — с `--dry-run` на небольшой папке.
